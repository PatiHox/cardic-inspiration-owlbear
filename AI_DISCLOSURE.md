# AI Use Disclosure

This extension — every line of code, styling, and documentation — was
written by an AI coding agent ([Claude Code](https://claude.com/claude-code)),
prompted and reviewed by a human maintainer. Nothing here was hand-written
first and cleaned up afterward.

## What that means in practice

- **Design and implementation**: All React/TypeScript source under
  [`src/`](src/), the extension manifest, build/deploy scripts, and this
  repository's documentation were generated by the AI agent from natural-
  language prompts.
- **Human role**: A human maintainer directed the work (what to build, in
  what order), reviewed the changes, ran it live in Owlbear Rodeo to check
  behavior, and asked for revisions where something was wrong or unwanted.
- **No claim of formal audit**: "Reviewed" means a human read the diffs and
  exercised the feature — not a professional security or accessibility
  audit. Treat this the same as you would any other small open-source
  extension: read the code if you depend on it for something that matters,
  and see the [README](README.md)'s note on the "secret card value" feature
  not being server-enforced.
- **Ongoing**: Future changes to this repository may continue to be written
  the same way.

## Why disclose this

Because it's true, and because "who/what wrote this" is relevant context
for anyone deciding whether to install an extension into their game or
trust its code. See the [repository](https://github.com/PatiHox/owlbear-ext)
for full source and history.
